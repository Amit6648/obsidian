
The hash maps are ==***data structures***== that store data in ==Key pair value== structure. These are used to retrieve, insert, update and delete data  quicky **(O(n))** 

# Syntax

 ### Creation 

```
unordered_map<type,type> map_name;
```

### Insertion

```
map_name[key] = value;
```

### Update

```
map_name[key]++;
map_name[key] =  another_value;
```

### Deletion

```
map_name.erase(key);
```

Stacks follows LIFO (Last in First out) order. Stacks are used to maintain a order throughout  operations like maintaining a [[Monotonic Stack]].

In stacks we can use operations like :
- **Push** - used to insert element in stack.
- **Pop** - used to delete element in stack.
- **Top** - used to view the top element at top.
---
# Syntax 

Creation

  ```
stack<type> stack_name;
  ```
---
Insertion

```
stack.push(value);
```
---
Access 

```
Stack.po
```

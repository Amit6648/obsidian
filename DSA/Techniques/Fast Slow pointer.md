In this technique we use two pointers a FAST pointer and  a SLOW pointer. So the fast pointer runs at the 2x speed of slow pointer. So this helps us find a loop in a list. The reason is that when we move the fast pointer it will always reach first at the end of list and when it will be at the end of list , the slow will be at list/2. Meaning if we were to take the fast at the start again when slow is at the middle both of them will reach end at the same time . So if there is loop or cycle in the list then the fast will cycle through the point creating cycle and then will eventually reach the slow pointer and we will know that there is a loop but if there is no loop fast will simple reach the end of the list.

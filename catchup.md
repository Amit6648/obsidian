So the catch up explains that where ever the problem is about catching up with  someone or something like time and distance problems we can use basic math formula of arrival time  

$$t = \frac{\text{Target} - \text{Position}}{\text{Speed}}$$
Note : we can't just simply compare two values and say if this element's time is greater than this element say it will collide with it . We have check it's starting location, if something is far behind the faster element then  how can it collide with that element if it the faster element will reach the collision point before the slower element.

So we always have to ensure that a element can only catch up to other element if the slower element is ahead of it not behind.
